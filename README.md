# Study02_ToDoList

매일 10~20개 정도의 할 일을 관리하는 개인용 할 일 관리 앱입니다. 현재는 기획 단계이며, 구현 전에 작성한 PRD 문서만 들어 있습니다.

## 목표

- 브라우저에서 파일을 열면 바로 실행됩니다.
- 새로고침해도 데이터가 사라지지 않습니다(`localStorage`).
- 순수 자바스크립트(HTML, CSS, JavaScript)로 만들며 서버와 외부 라이브러리를 쓰지 않습니다.

## 주요 기능

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류 (업무, 개인, 공부)
- 진행률 보기 (전체와 카테고리별)
